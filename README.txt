CineScope — Movie Recommendation & Box Office Analyzer

OFFLINE-FIRST VERSION
This version works without TMDB or any external API key. The catalogue contains 45 curated demo records across Tollywood, Bollywood, and Hollywood. Numeric ratings, posters, budget, and revenue are left blank where no sourced values are bundled; do not present these blank fields as zero.

Run on Windows:
1. Install Python 3.10 or newer.
2. Open this folder in File Explorer.
3. Click the address bar, type cmd, press Enter.
4. Run: py -m pip install -r requirements-web.txt
5. Run: py webapp.py
6. Open http://127.0.0.1:5000

Keep the terminal open while using the website. Press Ctrl+C in the terminal to stop it.

See WEB_DEPLOY_GUIDE.md for hosting instructions and OFFLINE_DATASET_INFO.txt for dataset notes.
